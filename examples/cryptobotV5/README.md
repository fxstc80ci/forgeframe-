## 1. Context

CryptoBot V5 is the project where ForgeFrame emerged as a mature reusable framework.

The original goal was to redesign a crypto futures trading bot into a state-of-the-art autonomous trading platform using:

```text
canonical market state
feature snapshots
specialist prediction models
signal fusion
risk authority
safe execution lifecycle
historical replay
ML training and calibration
vector analog retrieval
read-only dashboard truth
acceptance gates
```

---

## 2. Framework evolution observed

During the CryptoBot V5 build, the process evolved through several framework improvements:

```text
single design package
  -> task cards
  -> repo-root AGENTS.md
  -> autonomous build rules
  -> continuous autonomous mode
  -> extended task queue
  -> ML training design
  -> holistic completion review
```

---

## 3. Key lesson

A coding agent can move fast, but the repository must hold the doctrine.

The best outcomes came when missing instructions were not repeated in chat, but added to the repository as reusable framework artifacts.

---

## 4. Reusable pattern

CryptoBot V5 demonstrated this reusable pattern:

```text
GPT creates/refines build doctrine
Codex executes task cards
Git captures every checkpoint
Human monitors terminal and strategic direction
GPT reviews architecture and patches missing depth
Codex resumes with stronger instructions
```
